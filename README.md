# personalexpencetreaker# Personal Expense Tracker

A personal expense tracker built with **Python + Reflex** (UI), **Firebase Firestore** (database) and **Gemini** (AI).

## Features

- Add, edit and delete expenses (stored in Firestore)
- Filter by category, with a running total and per-category totals
- **Smart add:** type `Lunch 450 yesterday` and Gemini pre-fills the form for you to review
- **AI insights:** Gemini summarises your spending and suggests ways to save
- Light/dark mode

## Project layout

Reflex expects the app to live inside a folder named after the app, plus an `rxconfig.py` that `reflex init` generates for you.

```
expense_tracker/              <- project root
├── rxconfig.py               <- generated by `reflex init`
├── requirements.txt
├── README.md
├── .env                      <- your secrets (never commit)
├── serviceAccountKey.json    <- Firebase key (never commit)
└── expense_tracker/
    └── expense_tracker.py    <- the contents of app.py go here
```

## Setup

### 1. Create the project and install dependencies

```bash
mkdir expense_tracker && cd expense_tracker
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
# put requirements.txt in this folder, then:
pip install -r requirements.txt
reflex init                      # choose the blank template
```

`reflex init` creates `rxconfig.py` and `expense_tracker/expense_tracker.py`.
**Replace the contents of `expense_tracker/expense_tracker.py` with the provided `app.py`.**

### 2. Firebase (Firestore)

1. Go to the [Firebase console](https://console.firebase.google.com) and create a project.
2. Open **Build → Firestore Database → Create database** (Native mode).
3. Open **Project settings → Service accounts → Generate new private key**.
4. Save the downloaded file as `serviceAccountKey.json` in the project root.

The app uses the Firebase Admin SDK, which bypasses Firestore security rules. Keep your client-side rules locked down:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if false;
    }
  }
}
```

### 3. Gemini

Create an API key in [Google AI Studio](https://aistudio.google.com/apikey).

### 4. Environment variables

Create a `.env` file in the project root:

```env
FIREBASE_CREDENTIALS=serviceAccountKey.json
GEMINI_API_KEY=your-gemini-api-key
GEMINI_MODEL=gemini-2.5-flash
CURRENCY=PKR
```

`GEMINI_MODEL` and `CURRENCY` are optional. Change `GEMINI_MODEL` if you want a newer or different Gemini model.

### 5. Run

```bash
reflex run
```

Open http://localhost:3000.

## Data model

Collection `expenses`, one document per expense:

| Field        | Type      | Notes                                |
|--------------|-----------|--------------------------------------|
| `title`      | string    | e.g. "Groceries"                     |
| `amount`     | number    | greater than 0, rounded to 2 decimals |
| `category`   | string    | one of the categories in `app.py`    |
| `date`       | string    | ISO format, `YYYY-MM-DD`             |
| `note`       | string    | optional                             |
| `created_at` | timestamp | set by Firestore                     |
| `updated_at` | timestamp | set on edit                          |

## Security notes

- Add this to `.gitignore`:
  ```
  .env
  serviceAccountKey.json
  .venv/
  .web/
  __pycache__/
  ```
- The app has **no login**. That's fine for local personal use. If you deploy it publicly, add authentication first, otherwise anyone with the URL can read and change your data.
- Expense data (titles, amounts, categories, dates) is sent to the Gemini API when you use Smart add or AI insights.

## Troubleshooting

| Problem | Fix |
|---|---|
| `FileNotFoundError: serviceAccountKey.json` | Check `FIREBASE_CREDENTIALS` and that the file is in the project root. |
| `GEMINI_API_KEY is not set` | Add it to `.env` and restart `reflex run`. |
| Firestore permission or "API not enabled" error | Make sure Firestore is created and the Cloud Firestore API is enabled for the project. |
| Gemini model not found | Set `GEMINI_MODEL` in `.env` to a model available to your key. |
